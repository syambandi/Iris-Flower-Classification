# Iris Flower Classification

## Project Overview
A Machine Learning project that predicts Iris flower species based on four physical measurements.

## Dataset
- Dataset: Iris Dataset
- Total Records: 150
- Features: 4
- Target: Setosa, Versicolor, Virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Algorithm
Logistic Regression

## Project Workflow
1. Dataset loading
2. Data cleaning
3. Exploratory Data Analysis
4. Feature and target separation
5. Train-test splitting
6. Model training
7. Model evaluation
8. Model saving
9. New flower prediction

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

## Model Saving
The trained model is saved using Pickle.

## Conclusion
Successfully developed a Logistic Regression model to classify Iris flowers into three species.
